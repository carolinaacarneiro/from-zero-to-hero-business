From Zero to Hero · Guía del administrador

Todo lo que tu empresa necesita preparar antes del entrenamiento (Ciudad de México · 1 de diciembre de 2026).

1 vezel Setup, 10–15 min
3 minla verificación de cada participante
0permisos manuales durante el evento

Cronograma

T − 10 días

Preparar el workspace

  1. Elegir el workspace corporativo (desarrollo o dedicado al entrenamiento). No producción ni Free Edition.
  2. Confirmar que tienes administrador de cuenta (menú de usuario → Manage account).
  3. Agregar a todos los participantes al workspace: Settings → Identity and access → Users → Add user.
T − 7 días

Ejecutar el Setup

  1. Workspace → Create → Git folder con https://github.com/carolinaacarneiro/from-zero-to-hero-business.
  2. Abrir 00 - Setup y teardown/notebooks/00_setup → Connect → Serverless.
  3. Ejecutar las dos primeras celdas, marcar a los participantes en 4. Participantes y hacer Run all.
  4. Confirmar ✅ VERIFICACIONES COMPLETAS y enviar el bloque Evidencia del Setup al equipo de Databricks.
T − 5 días

Verificación de cada participante

  1. Enviar a cada participante el enlace del repositorio y la instrucción de ejecutar 00_verificar_ambiente.
  2. Cada participante escribe su schema (ej.: ggarcia), hace Run all y te envía su resumen 🟢/🟡/🔴.
  3. Resolver los 🔴 con la tabla de soluciones de abajo.
T − 1 día

Último control

  1. Volver a ejecutar 00_setup si se sumaron participantes (es idempotente).
  2. Abrir Genie One una vez (selector de apps → Genie One, o /one) para confirmar el acceso.
  3. Confirmar que el repositorio es público el día del evento (los imports por URL y el logo dependen de eso).
Después

Teardown

  1. Abrir 00_teardown → Connect → Serverless → Run all.
  2. Por defecto elimina las apps de la clase, el grupo, el warehouse y el cluster. El catálogo no se borra salvo que lo actives.

🧯 Si algo sale mal

Catálogo 'fromzerotohero' no puede crearse automáticamenteCrear el catálogo a mano (Catalog → + → Create a catalog, con Storage location), poner 1. Crear catálogo = false y repetir Run all.
Error 403 de almacenamiento / 'no puede escribir en el almacenamiento del catálogo'Eliminar el catálogo vacío, completar 1b. Ubicación gestionada con una ruta de una External Location del workspace y repetir Run all.
Requiere ADMIN DE CUENTAEjecutar con un administrador de cuenta, o crear el grupo fromzerotohero_workshop en la consola de la cuenta y asignarlo al workspace.
Participante 'no encontrado como usuario de cuenta'Agregarlo al workspace y volver a ejecutar el Setup.
❌ Endpoints del ai_queryLos modelos no están en la región: avisar al instructor (se usa otro modelo).
❌ Genie Agents / Databricks Apps / Unity GatewayHabilitar la funcionalidad en Settings → Previews o consultar al equipo de cuenta.
Participante 🔴 en 'Crear tu schema'Falta CREATE SCHEMA: confirmar que está en el grupo y repetir el Setup.
Participante 🔴 en el warehouseFalta CAN USE en fromzerotohero_workshop_wh: repetir el Setup.
